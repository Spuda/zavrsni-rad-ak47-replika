# zavrsni-rad-ak47-replika
Završni rad za zanimanje *Strojarski računalni tehničar*, Tehnička škola Karlovac (2026.).
Mentor: Anto Gagula, dipl. ing.

> ⚠️ **Napomena:** Ovo je nefunkcionalna replika (prop) izrađena u edukativne svrhe.
> Ne ispaljuje streljivo i nije oružje.

## O projektu
Zadatak je bio konstruirati repliku automatske puške AK-47 i izraditi je
aditivnom tehnologijom (FDM 3D printanje), uz pripadajuću tehničku dokumentaciju.

Kroz rad sam obradio:
- princip rada FDM 3D printera
- mogućnosti primjene aditivne proizvodnje
- karakteristike korištenih materijala
- pripremu modela za printanje (CAD → slicer → G-code)
- utjecaj parametara printanja na kvalitetu dijelova

## Proces izrade
1. **Modeliranje** u CAD-u: Catia
2. **Priprema za ispis** u Bambu Studiju (slicing, orijentacija dijelova, potpore)
3. **Printanje** na Bambu Lab X1 Carbon (FDM, radni prostor 256×256×256 mm)
4. **Obrada i sastavljanje**: `<brušenje, bojanje, spajanje>`
5. **Tehnička dokumentacija**: radionički crteži i sklopni crtež

## Korištene tehnologije
| | |
|---|---|
| CAD | Catia |
| Slicer | Bambu Studio |
| Printer | Bambu Lab X1 Carbon |
| Materijal | PLA |
